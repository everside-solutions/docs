### Initial Requirements

- Java 21
- Velocity
- LimboAPI

### Installing Guide

1. Download [Velocity](https://papermc.io/downloads/velocity), [LimboAPI](https://modrinth.com/plugin/limboapi) and [AntiBot](https://builtbybit.com/resources/32549/).
2. Copy downloaded `velocity-{VERSION}.jar` into your server home directory.
3. Create directory `plugins` in your server home directory.
4. Copy downloaded `limboapi-{VERSION}.jar` and `antibot-plugin.jar` into plugins directory.
5. Start server by running `java -jar velocity-{VERSION}.jar` inside your server home directory.
6. Done! Everything should work propertly, if you have troubles with running AntiBot, please contact with our support using discord.
