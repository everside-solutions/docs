title: ",connect"
---

A command that connect user to specified remote server.

### Parameters

<Tabs>
  <Tab title="Host">
    Address of server where you'll be connected.

    **Examples:**

    - mc.hypixel.net
    - 21.37.42.00
  </Tab>
  <Tab title="Port">
    Port of server where you'll be connected.\
    **Range:** 0 - 65535

    **Examples:**

    - 25565
    - 2137
    - 42069

    <Tip>
      If you provide `0` as port, proxy will try to automatically resolve it using `_minecraft` SRV domain record.
    </Tip>
  </Tab>
  <Tab title="Proxy">
    Type of proxy address which'll be used to connect with remote server.

    **Types:**

    | Name            | Description                                                                                                                                                                                                                              | Requirement  |
    | :-------------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------: |
    | **PUBLIC**      | An address from public proxy lists.                                                                                                                                                                                                      | **NONE**     |
    | **PRIVATE**     | An address purchased from a proxy seller with limited number of users.                                                                                                                                                                   | **STANDARD** |
    | **RESIDENTIAL** | An proxy address that uses a real IP from a home device to make connection appear as legitimate.<br />_More Information:_ [_en.wikipedia.org/wiki/Proxy_server_](https://en.wikipedia.org/wiki/Proxy_server#Residential_proxy_\(RESIP\)) | **PREMIUM**  |
    | **OWN**         | An pool of addresses managed directly by user with `,ownproxies` command.                                                                                                                                                                | **STANDARD** |

    <Tip>
      You can enter country in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format after colon to connect only from proxy address that belongs to specified country, e.g. `private:pl` means you'll be connected using private proxy address with ip address from Poland.
    </Tip>
  </Tab>
  <Tab title="Name">
    The name under which you'll connect with remote server.\
    **Length:** 3 - 16

    <Tip>
      You can also use a string generator options in parameter name, e.g. `[n:5]` , `[real]` , `[n:2]_esPr0xy_[s:4]` etc., available options are listed below.

      | Option     | Brief                                          | Example Result                  |
      | :--------: | :--------------------------------------------: | :-----------------------------: |
      | **[s:α]**  | Letter-only random string with **α length**.   | wvDzTTaV, yyGbVVPo, etc.        |
      | **[n:α]**  | Digit-only random string with **α length**.    | 24521235, 39002113, etc.        |
      | **[r:α]**  | Random string with **α length**.               | sw9vDzTwMu, TE60fLswqu etc.     |
      | **[real]** | An real nickname generated using common words. | MasterMind666\_, GoMen2233 etc. |
    </Tip>
  </Tab>
</Tabs>

### Example Commands

- `,connect hypixel.net 0 private:pl Mario_[s:4]`
- `,connect 21.37.42.00 666 residential esPr0xy_[r:4]`
