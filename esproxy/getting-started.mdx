**esProxy** is an advanced tool for testing Minecraft servers against bots, cheaters and exploits.

Our tool is an **SaaS application** hosted in cloud accessible through Internet network for users which want to test their server network against **bots**, **cheaters** and **exploits**.

Also our tool has many useful features which will help users to test if server has good protection such as **automatic captcha solving**, **premium account manager**, **bot physics simulation** and many more.

### User Manual

You can find a lot of information in this documentation, including examples of how to use specific functions in the proxy, what they exactly do, what their requirements are, etc.

We have divided the documentation into several categories to make it more readable and transparent for users. So for example documentation dedicated to commands can be found in appropriate category.

We also provide support for customers in discord tickets, but if something is in documentation our support agent will redirect you to documentation.

### Accessing Proxy

To use proxy, you must be running **Minecraft 26.1**, have purchased access, and join Minecraft server at **szpont.ing**.

After connecting, you must authorize yourself using password. We recommend using a password that have **at least 8 characters** and includes special characters.

<Check>
  All types of passwords are encrypted using the strong [Argon2](https://en.wikipedia.org/wiki/Argon2) algorithm.
</Check>

<Note>
  During registration, your ISP will be recorded in order to block access to your account to other users. If you change your internet provider, you will need to contact us.
</Note>
